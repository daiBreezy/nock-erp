# 🧮 ส่วนที่ 1 — ถาม KMD (สำนักงานบัญชี)

## A. VAT (บล็อกหนักสุด — กระทบ 3 workflow)
1. บริษัท **Liclass Education Co., Ltd. มี ภ.พ.20 (จด VAT) ไหม?**
2. Admin บอกว่า "VAT แล้วแต่สาขา" — จริงๆ VAT **ผูกกับอะไร**? สาขา / ประเภทสินค้า-บริการ / สายธุรกิจ (Liclass-ไทย-ญี่ปุ่น / NA App)?
3. รายได้ตัวไหน **เสีย VAT** / ตัวไหน **ยกเว้น**? — ค่าเรียน / ค่าหนังสือ / ค่ารถ / ค่าสอบ / **NA App (digital service)**
   > ปลดล็อก: Invoice tax code ราย line · Sales Tax report · ออกใบกำกับภาษี

## B. WHT / e-WHT
4. **ทำไมเราไม่ใช้ e-Withholding Tax ผ่านธนาคาร?** มีข้อจำกัดอะไร? (AIS/True/Fujifilm ใช้อยู่แล้ว — ขยายให้ครบได้ไหม)
5. **50 ทวิ ต้องเซ็นด้วยมือจริงไหม?** (ข้อหารือ กค 0702/1057 บอกว่าใช้ลายเซ็นอิเล็กทรอนิกส์ได้) — และการที่ Shibasan **เซ็นใบเปล่าไว้ล่วงหน้า** มีความเสี่ยงทางกฎหมายแค่ไหน?
6. **ค่าน้ำ / ค่าไฟ ที่จ่ายผู้ให้เช่า** ต้องหัก WHT ไหม? (จ่ายการไฟฟ้าตรง = ไม่หัก · จ่ายผู้ให้เช่า = ?)
7. **SaaS ต่างประเทศ (Zoom/Figma/Gather)** — ต้องหัก ภ.ง.ด.54 ไหม? ต้องยื่น **ภ.พ.36** ไหม?
   > ปลดล็อก: WHT engine · Vendor master · Overseas payment

## C. รายละเอียดบิลค่าเช่า (จาก Vendor Doc จริง)
8. บิลค่าเช่าที่แตกหลายหมวด (ค่าเช่า 5% + ค่าบริการ 3% + **ค่าภาษีที่ดินและสิ่งปลูกสร้าง** + **ค่าบริการอุปกรณ์**) — แต่ละหมวดคิด WHT ยังไง ถูกต้องไหม?
9. บิลที่มี **VAT 7% + WHT พร้อมกัน** — ลำดับคำนวณ (หักจากฐานก่อน/หลัง VAT)?
   > ปลดล็อก: WHT line-level logic (spec 03)

## D. เอกสาร & กระบวนการ
10. **เลขที่เอกสารแบบใหม่** `INV[YYMMdd]-[biz]-[branch]-[run]` + RE reflect INV — **ผ่าน audit ไหม?** running number ควร reset เมื่อไหร่ (ต่อวัน/เดือน/ปี/สาขา)?
11. **unearned revenue** (เงินรับล่วงหน้า ยังสอนไม่ครบ = หนี้สิน) — ตอนนี้ **ใครคำนวณ**? เราต้องส่งตัวเลขนี้ให้ไหม?
12. **ส่วนลดพี่น้องข้ามสายธุรกิจ** (ลดบน INV Liclass เพราะพี่เรียน NAS) — กระทบการบันทึกบัญชี/VAT ไหม?
13. **Deadline จริง** ที่ KMD ต้องได้เอกสารแต่ละเดือน (เพื่อยื่นภาษีทัน) — ค่าปรับที่โดนมาจากอะไร?
14. รับเอกสารเป็น **ไฟล์ดิจิทัล** ได้ไหม? อยากได้ **ฟอร์แมตไหน**? ขอ **checklist เต็ม** ที่ต้องการทุกเดือน
    > ปลดล็อก: Document export · Period Close automation · เลิกปริ้น/จับชุด
