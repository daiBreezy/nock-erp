## 📌 วิธีสัมภาษณ์ (อ่านก่อน 2 นาที)

| ทำ ✅ | อย่าทำ ❌ |
|---|---|
| **นั่งดูเขาทำจริง** (job shadowing) 1 รอบเต็ม | ถามผ่าน chat แล้วเชื่อคำตอบ |
| ขอเปิดไฟล์จริงของเดือนที่แล้วให้ดู | ให้เขาอธิบายจากความจำ |
| ถาม "ครั้งล่าสุดที่มันพังคือเมื่อไหร่" | ถาม "มีปัญหาอะไรไหม" (ตอบว่าไม่มีเสมอ) |
| นับจำนวนจริง (กี่ไฟล์ กี่คลิก กี่นาที) | รับคำว่า "เยอะ" "นาน" "บ่อย" |
| ถามซ้ำ 3 ครั้งด้วยคำต่างกัน | รับคำตอบแรกเป็นข้อสรุป |
| อัดเสียง / จดคำพูดดิบๆ | สรุปความเองระหว่างฟัง |

**สัญญาณว่ากำลังจะได้ข้อมูลปลอม:** Admin ตอบเร็วเกินไป · ตอบว่า "แล้วแต่" · ตอบว่า "ก็ทำๆ ไป"
→ ให้ขอตัวอย่างจริง 1 เคสทันที

**ถ้าคำตอบคือ "ไม่รู้" — จดว่า "ไม่รู้"** ห้ามเดาแทนเขา นี่คือข้อมูลที่มีค่าที่สุด

# 🔵 A. ภาพรวมโครงสร้าง (ถามก่อนอย่างอื่น)

> ถ้าข้อ A1 ตอบว่า "คนละบริษัท" — หยุดสัมภาษณ์ แล้วกลับมาคุยกันใหม่ ทุกอย่างเปลี่ยน

- [ ] **A1** `Liclass` / `NA App` / `NA School` — เป็น **บริษัทเดียวกัน** หรือ **คนละนิติบุคคล**?
- [ ] **A2** ถ้าบริษัทเดียวกัน — ทำไมถึงแยกบัญชีธนาคาร? ใครเป็นคนตัดสินใจแยก?
- [ ] **A3** แต่ละสายขายอะไร ให้ใคร? (`NA App` คือแอป? ขายใคร? `NA School` ต่างจาก Liclass ยังไง?)
- [ ] **A4** 5 สาขา (Sukhumvit/Silom/Bang-Na/Sriracha/Pattaya) ผูกกับสายธุรกิจไหนบ้าง? สาขาหนึ่งขายได้หลายสาย?
- [ ] **A5** มีสาขาไหนเป็นแฟรนไชส์ / หุ้นส่วนคนอื่นไหม?
- [ ] **A6** Admin มีทั้งหมดกี่คน? แบ่งงานกันยังไง — ตามสาขา ตามสายธุรกิจ หรือตามประเภทงาน?
- [ ] **A7** ใครเป็น "Master Admin" (คนที่ออก Invoice/Receipt ได้) — มีกี่คน?

# 🔵 B. บัญชีธนาคาร & การเคลื่อนไหวของเงิน

- [ ] **B1** ทั้งบริษัทมีบัญชีกี่ใบ? (ในภาพเห็น 4 — มีมากกว่านั้นไหม? **บัญชีเงินฝากประจำ? บัญชีของสาขา?**)
- [ ] **B2** แต่ละใบ **รับอะไร / จ่ายอะไร** — ขอทีละใบ
- [ ] **B3** **PDF Currency Kbank statement** ในผังคืออะไร? บัญชีเงินตราต่างประเทศ? รับ/จ่ายสกุลอะไร?
- [ ] **B4** **Credit Advice statement** คืออะไร ใช้ทำอะไร ทำไมต้อง "โทรหา KBiz" ถึงจะได้มา?
- [ ] **B5** การโอนเงินจาก Income → Outcome ทำ **ด้วยมือ** หรือ **auto sweep**? ทำเดือนละกี่ครั้ง? ใครทำ?
- [ ] **B6** มี **บัตรเครดิตบริษัท** ไหม? กี่ใบ? อยู่กับใคร? ตัดจากบัญชีไหน?
- [ ] **B7** ใครมีสิทธิ์กดเงินออกจากบัญชี Outcome ได้บ้าง? ต้องอนุมัติกี่คน?
- [ ] **B8** 🔥 **Shibasan จ่ายเงินออกจากบัญชีบริษัทตรงๆ ได้เลยไหม** โดยไม่ผ่าน Request?
    - ถ้าได้ — เดือนหนึ่งประมาณกี่รายการ? เป็นค่าอะไร?
    - รายการพวกนี้ Admin รู้ล่วงหน้าไหม หรือมาเจอตอนโหลด statement?
- [ ] **B9** เคยมีรายการใน statement ที่ **ไม่มีใครรู้ว่ามันคืออะไร** ไหม? แล้วทำยังไง?

# 🔵 C. เงินเข้า — Invoice / Payment / Receipt

### C1. ก่อนออกบิล
- [ ] **C1.1** Invoice หนึ่งใบ ใช้เวลาสร้างกี่นาที?
- [ ] **C1.2** ข้อมูลบนบิลมาจากไหนบ้าง? (ระบบ / Sheet ไหน / ถามครู / จำเอา) — **ขอชี้ทีละบรรทัดบนบิลจริง**
- [ ] **C1.3** ค่า **Book / Bus / Exam** รู้ได้ยังไงว่าเด็กคนนี้ต้องจ่าย? ใครบอก? จดไว้ที่ไหน?
- [ ] **C1.4** เคยลืมใส่ค่าอะไรลงบิลไหม? ครั้งล่าสุดเมื่อไหร่? เกิดอะไรขึ้น?

### C2. Teacher Re-check
- [ ] **C2.1** ครูตรวจ **อะไรบ้าง** บนบิล? (ชั่วโมง? ราคา? ชื่อ? หนังสือ?)
- [ ] **C2.2** ครูทักบ่อยแค่ไหน? 10 ใบ ทักกี่ใบ?
- [ ] **C2.3** ครูทักเรื่องอะไรบ่อยที่สุด?
- [ ] **C2.4** ถ้าครูไม่ตรวจ จะเกิดอะไรขึ้น? เคยเกิดไหม?

### C3. ส่งบิล + รับเงิน
- [ ] **C3.1** "Webform" ที่ส่งให้ผู้ปกครอง — ใครสร้าง? สร้างด้วยอะไร? ต่อกับ Sheet ไหน?
- [ ] **C3.2** ผู้ปกครองโอนเงินยังไง? มี **QR** ไหม? เลขบัญชีเดียวกันทุกคนใช่ไหม?
- [ ] **C3.3** 10 คน ส่งสลิปผ่าน **Webform กี่คน / LINE กี่คน**?
- [ ] **C3.4** สลิปที่มาทาง LINE — ตอนนี้เก็บไว้ที่ไหน? (เครื่องส่วนตัว?) หายไหม?
- [ ] **C3.5** ⏱ **จับเวลาจริง**: เทียบสลิป 1 ใบกับ KBiz ใช้เวลากี่นาที?

### C4. เคสที่ไม่ปกติ (สำคัญมาก — ถามทีละข้อ อย่ารีบ)
- [ ] **C4.1** ผู้ปกครองโอน **ยอดไม่ตรง** (ขาด/เกิน) เคยเกิดไหม? ทำยังไง?
- [ ] **C4.2** แม่โอน **ยอดเดียวรวมลูก 2 คน** เคยไหม? ทำยังไง?
- [ ] **C4.3** โอนจาก **บัญชีคนอื่น** (ปู่ย่า/บริษัทพ่อ) ชื่อไม่ตรง — รู้ได้ยังไงว่าเป็นของใคร?
- [ ] **C4.4** ผู้ปกครอง **ส่งสลิปเก่าซ้ำ** เคยเจอไหม? จับได้ยังไง?
- [ ] **C4.5** จ่าย **เงินสด** ที่สาขา — จริงๆ ไม่เคยมีเลยใช่ไหม? แล้วเงินสดจากไหนใน petty cash?
- [ ] **C4.6** Invoice **ส่งไปแล้วผิด** ทำยังไง? ยกเลิกยังไง? เคยเกิดไหม?
- [ ] **C4.7** ผู้ปกครอง **ขอเงินคืน / ยกเลิกกลางคอร์ส** เคยเกิดไหม? คืนยังไง? คิดเงินยังไง?
- [ ] **C4.8** ผู้ปกครอง **ไม่จ่ายสักที** เคยเกิดไหม? ปล่อยไว้กี่วัน? แล้วยังไงต่อ?
- [ ] **C4.9** เคย **ออกใบเสร็จให้คนที่ยังไม่จ่าย** ไหม? (เพราะเชื่อสลิป แต่เงินไม่เข้า)

### C5. Receipt
- [ ] **C5.1** ต้องรอ 1 วันเพื่อเช็ค KBiz จริงไหม? แล้วผู้ปกครองบ่นไหม?
- [ ] **C5.2** ใบเสร็จมีเลขที่ไหม? เลขรันจากอะไร? มีเลขซ้ำ/ข้ามเคยเกิดไหม?
- [ ] **C5.3** ใบเสร็จส่งทางไหน? ผู้ปกครองขอย้อนหลังบ่อยไหม? หาเจอไหม?

# 🔵 D. เงินออก — Expense / Petty Cash / Request

- [ ] **D1** เดือนหนึ่งมีรายการจ่ายทั้งหมดประมาณกี่รายการ?
- [ ] **D2** กี่ % ผ่านระบบ Request / กี่ % จ่ายตรงไม่ผ่านระบบ?
- [ ] **D3** **Petty cash** แต่ละสาขาได้เงินยังไง? เติมบ่อยแค่ไหน? ใครถือเงินสด?
- [ ] **D4** Petty cash **ขาด/เกิน** ตอนนับสิ้นเดือน เคยไหม? ทำยังไง?
- [ ] **D5** **Pay Voucher** เขียนด้วยอะไร? กี่ใบต่อเดือน? ใช้เวลาใบละกี่นาที?
- [ ] **D6** ทำไมต้องมี **ต้นฉบับ + สำเนา**? ใครเก็บอันไหน? ใช้ทำอะไร?
- [ ] **D7** ใบเสร็จ/ใบกำกับภาษีจาก vendor — เก็บยังไง? หายบ่อยไหม? ตามทวงบ่อยไหม?
- [ ] **D8** มี vendor ประจำกี่เจ้า? มีทะเบียนรวมไว้ที่ไหนไหม? (ชื่อ/เลขผู้เสียภาษี/เลขบัญชี)
- [ ] **D9** จ่ายค่าอะไรบ้างเป็นประจำทุกเดือน? (ค่าเช่า/น้ำ/ไฟ/เน็ต/…) — **ขอรายการเต็ม**

# 🔵 E. WHT (หัก ณ ที่จ่าย) — ถาม Admin เฉพาะ "ทำยังไง" ห้ามถาม "ต้องทำยังไง"

### E1. ปริมาณ & ประเภท
- [ ] **E1.1** เดือนที่แล้ว หัก WHT ทั้งหมด **กี่รายการ**? — 🔥 **ขอนับจริงจากแฟ้ม อย่าให้ประมาณ**
- [ ] **E1.2** หักให้ vendor กี่เจ้า? ประจำกี่เจ้า / ขาจรกี่เจ้า?
- [ ] **E1.3** ขอ **รายการเต็ม** ว่าหักค่าอะไรบ้าง และหักกี่ % — ทำเป็นตาราง:

    | vendor | ค่าอะไร | บุคคล/นิติบุคคล | % ที่หัก | ยอดต่อเดือน |
    |---|---|---|---|---|
    |  |  |  |  |  |

- [ ] **E1.4** 🚩 **ค่าน้ำ / ค่าไฟ หัก WHT ด้วยหรือเปล่า?** จ่ายให้ใคร — การไฟฟ้าโดยตรง หรือ **ผู้ให้เช่าอาคาร**?
- [ ] **E1.5** "อื่นๆ สารพัด" ที่บอก — **ขอชื่อจริงทุกตัว** ห้ามเหลือคำว่าอื่นๆ
- [ ] **E1.6** รู้ได้ยังไงว่า vendor แต่ละเจ้าต้องหักกี่ %? ดูจากไหน? จำเอา? มีตารางไหม?
- [ ] **E1.7** เคย **หักผิด %** ไหม? รู้ตอนไหน? แก้ยังไง?

### E2. วิธีทำวันนี้
- [ ] **E2.1** เขียน **50 ทวิ** ด้วยอะไร? (มือ / Word / ซื้อฟอร์มมากรอก / โปรแกรม)
- [ ] **E2.2** ใบละกี่นาที? เดือนหนึ่งใช้เวลารวมกี่ชั่วโมง?
- [ ] **E2.3** เลขที่หนังสือรับรอง รันยังไง? ใครคุมเลข?
- [ ] **E2.4** ทำกี่ชุด? ให้ใครบ้าง? (vendor / เก็บเอง / KMD)
- [ ] **E2.5** Shibasan เซ็นกี่ใบต่อเดือน? เซ็นทีเดียวหรือทยอยเซ็น? รอนานไหม?
- [ ] **E2.6** หลังเซ็นแล้วต้องสแกนไหม? ใครสแกน? เก็บที่ไหน?
- [ ] **E2.7** ส่ง 50 ทวิ ให้ vendor ยังไง? (ไปรษณีย์? มือ? อีเมล?)
- [ ] **E2.8** vendor เคย **ทวง 50 ทวิ** ไหม? เคยทำหายไหม? เคยต้องออกใหม่ไหม?

### E3. การนำส่ง
- [ ] **E3.1** ส่งข้อมูล WHT ให้ KMD ยังไง? รูปแบบไหน? วันที่เท่าไหร่ของเดือน?
- [ ] **E3.2** KMD เคย **ตีกลับ** เพราะข้อมูล WHT ไม่ครบไหม? เพราะอะไร?
- [ ] **E3.3** เคยยื่นเลยกำหนด / โดนค่าปรับไหม?
- [ ] **E3.4** ⏱ WHT ทั้งกระบวนการ กินเวลา Admin กี่ชั่วโมง/เดือน?

# 🟠 F. คำถามสำหรับ Shibasan (CEO) — Admin ตอบแทนไม่ได้
