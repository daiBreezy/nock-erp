# Packages & Access Model

> สถานะ: 🟢 confirmed (จาก user) · ปัจจุบันมี **4 Package** ให้เลือก
> เรื่องนี้กระทบ access ทั้งระบบ โดยเฉพาะสิทธิ์ดู **Live stream**

## User Tiers
| Tier | คือ | สิทธิ์ |
|------|-----|--------|
| **Guest** | ฟรี ยังไม่สมัคร | ดูคลิปฟรีที่กำหนด |
| **Free User** | สมัครแล้ว ยังไม่จ่าย | ดูคลิปฟรีที่กำหนด |
| **Premium** | สมัคร+จ่าย ซื้อ Package | ดูวิดีโอย้อนหลังได้ (รวม Live ที่กลายเป็น record) |
| **Premium Plus (P+)** | Package แบบช่วงเวลา (มาใหม่) | **ดู Live stream สด ได้** |
| **Premium [โรงเรียน]** | เจาะจงโรงเรียน (อนาคตเร็วๆ นี้) | ดู Live + record **เฉพาะของโรงเรียนตัวเอง** |

## Package Types
### Premium (ธรรมดา) — กำลังจะยกเลิกเร็วๆ นี้
- Duration: **3, 6, 12, 18, 24, 36 เดือน** (ยิ่งนาน ราคาเฉลี่ย/เดือนยิ่งถูกลง)
- ดูวิดีโอย้อนหลังได้ (รวม Live ที่เป็น record แล้ว)

### Premium Plus (P+) — มาใหม่ · ดู Live สดได้
- เป็น **Package ช่วงเวลา (duration window)** เปิดเป็นรอบ เช่น 1 Mar – 31 Jul
- **ราคาลดลงตามวันที่เหลือ** (dynamic pricing):
  - ราคาเต็ม เช่น 5,000 / ระยะ 4 เดือน (120 วัน) → เฉลี่ย ~41 บาท/วัน
  - ซื้อวันที่ 12 Apr (ผ่านไป 42 วัน): 5,000 − (42 × 41) = 5,000 − 1,722 = **3,278** (ราคา ณ วันนั้น)
  - **ราคาต่ำสุด = 500** (ไม่ลดต่ำกว่านี้ ไม่ว่าจะเหลือกี่วัน)

### Premium [ชื่อโรงเรียนดัง] [จำนวนสัปดาห์] — อนาคต
- เช่น Premium Suankularb / Premium Triem Udom / Premium Assumption
- ราคา **ยังไม่กำหนด**
- **ดูได้เฉพาะของ Package ตัวเอง** (Suankularb เห็น/ดู Live + record ของ Suankularb เท่านั้น ข้ามโรงเรียนไม่ได้)

## สิทธิ์ดู Live Stream (สำคัญ)
- **Live สด:** ดูได้เฉพาะ **Premium Plus (P+)** เท่านั้น
- **Live ที่กลายเป็น record (ย้อนหลัง):** Premium ธรรมดา ก็ดูได้
- **อนาคต:** Live สด = เฉพาะ P+ เท่านั้น + จะมี Live type ใหม่ = เจาะจงเฉพาะ Package (โรงเรียน)
- **ช่วงเปลี่ยนผ่าน (Premium ธรรมดากำลังยกเลิก):**
  - คนที่จ่ายแบบ **ตัดบัตร (recurring)** → ยังดู Live (แบบ P+) ได้ จนกว่าจะยกเลิกการตัดบัตร (ยกเลิกแล้ว = ดู Live ไม่ได้)
  - คนที่จ่าย **รายเดือน (ไม่ตัดบัตร)** → ดู Live ไม่ได้แล้ว หลัง Package เดือนปัจจุบันหมด

## Implication ต่อ UI (ต้องรองรับ)
- การ์ด/หน้า Live ต้องเช็คสิทธิ์ P+ ก่อนเข้าชมสด
- Paywall ของ Live ต่างจาก clip ปกติ (ชวนอัปเป็น P+ ไม่ใช่ Premium ธรรมดา)
- Premium โรงเรียน → ต้อง filter เนื้อหาตาม package ของ user
- Pricing page ต้องโชว์ P+ แบบ dynamic price (ราคา ณ วันนี้ + วันหมดเขต)
