## เจตนาของหน้า (Page Intent) — Confirmed ✅
หน้านี้คือ **Conversion Funnel** ไม่ใช่แค่ที่ดูคลิป มี 2 user segment:

| User | สถานะ | Primary Action |
|------|--------|----------------|
| ยังไม่สมัคร | Guest | **สมัครฟรี** (เก็บ lead) |
| สมัครแล้ว (ฟรี) | Member | **จ่ายเงิน** (ซื้อแพ็กเกจ) |

→ implication: หน้า Clip ควรปรับการแสดงผลตามสถานะ login (guest vs member)
→ Pricing + ห้องสอบ: **เก็บไว้ แต่จัดวางใหม่** (ไม่ตัดออก)

## Access Tiers — Confirmed ✅
| Tier | คลิปย้อนหลัง | ไลฟ์สด |
|------|--------------|--------|
| Guest (ยังไม่สมัคร) | เฉพาะคลิปที่ตั้งเป็น "ฟรี" | **ต้องสมัครฟรีก่อน** |
| Free User (สมัครฟรี) | เฉพาะคลิปที่ตั้งเป็น "ฟรี" | ดูได้ทั้งหมด |
| Member (จ่ายเงิน) | **ดูได้ทั้งหมด** | ดูได้ทั้งหมด |

→ implication: การ์ดคลิปต้องมี state "ฟรี" vs "ล็อก" + มี paywall ตอนกดคลิปที่ล็อก
→ **ไลฟ์สด = lead magnet**: Guest กดดูไลฟ์ → เด้งให้สมัครฟรีก่อน (Free+ ดูได้)

## Audience: Landing vs Clip — Confirmed ✅
| | Audience | บทบาท | เป้าหมายหน้า |
|---|----------|--------|--------------|
| Landing | **ผู้ปกครอง** | ผู้จ่าย/ตัดสินใจ | Present ข้อมูลบริษัท สร้าง trust |
| Clip | **นักเรียน** | ผู้ใช้งานจริง | ดู/ค้นหาคลิป + paywall ชวนจ่าย |

→ 2 หน้าต้องแยกขาดจากกัน (คนละ persona, คนละ tone)
→ ประเด็นออกแบบ: คนใช้=นักเรียน แต่คนจ่าย=ผู้ปกครอง → CTA paywall ต้องออกแบบให้เด็ก "ส่งต่อ" ถึงผู้ปกครอง

## Paywall Flow — Confirmed ✅
```
Guest  กดคลิปล็อก → เข้าหน้าดูคลิปนั้น → เด้ง Modal "สมัครฟรี (Signup)"
Free   กดคลิปล็อก → เข้าหน้าดูคลิปนั้น → กด Play → เด้ง "Payment" (ชวนจ่าย/สมัครใช้บริการ)
Member กดคลิปใดๆ  → เล่นได้เลย
```
→ ทั้ง Guest/Free เข้าหน้าดูคลิปได้ แต่ gate ต่างจังหวะ (Guest=signup เร็ว, Free=payment ตอนกด Play)

## Zone Live — Confirmed ✅
- ไลฟ์สด **สำคัญมาก ควรเด่น** ในหน้า Clip
- **หลายไลฟ์พร้อมกัน:** ช่อง A + ช่อง B ไลฟ์เวลาเดียวกัน → แสดง **วางข้างกัน**
  - 1 วัน รวม 6–8 ไลฟ์ (A 3–4, B 3–4 ตรงเวลากัน)
  - เผื่อ **ช่อง C** อนาคต → layout ต้อง scale หลายช่อง (คอลัมน์ต่อช่อง แบบ Calendar)
- ตารางไลฟ์วันต่อไป: นักเรียน **ตั้งเตือน / เพิ่มลงปฏิทิน** ได้
- Lifecycle: **ไลฟ์จบ → กลายเป็นวิดีโอย้อนหลัง (เดี่ยว) อัตโนมัติ** แล้วค่อยจับรวมเป็น Video Group ทีหลัง
- **Icons:** ใช้ Material Icons/Symbols ทั้งหมด (ห้าม emoji) · Date = `dd Mon yy` (เช่น 22 Sep 26)
- การ์ดไลฟ์ = **วิดีโอ preview** (ไม่ใช่ gradient) + overlay ให้อ่านออก
- **เปิดเสียงได้ทีละไลฟ์เท่านั้น** (unmute ไลฟ์นึง → ไลฟ์อื่น mute อัตโนมัติ) + ปุ่ม mute มุมการ์ด
- แสดง **จำนวนผู้ชมสด** ("ผู้ชมกำลังดู xxx คน")
- 1 ไลฟ์ **อาจเป็นหลายระดับชั้น (multiple grade)** ไม่เจาะจง grade เดียว → แสดงเป็น chip หลายอัน
