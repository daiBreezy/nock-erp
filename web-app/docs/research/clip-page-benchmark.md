# Research — Clip Page Benchmark & Best Practices

> สวมหมวก Researcher — รวบรวม best practice ที่ตรงกับ 3 ฟีเจอร์หลัก + paywall ของเรา
> วันที่: 2026-06-24

## 1. Browse คลิป (Card / Grid / Library)
**อ้างอิง:** Domestika, Skillshare, Udemy, Khan Academy

- **Card ต้องไม่ยัดข้อมูลเกิน** — รายละเอียดมากไป = รก; เลือกเฉพาะข้อมูลที่ช่วยตัดสินใจ
  → ใช้กับเรา: clip **group** card ควรโชว์แค่ ชื่อ / วิชา-ระดับ / จำนวนวิดีโอ / ความยาวรวม / ป้ายฟรี-ล็อก
- **Card ต้อง responsive** เก็บข้อมูลครบทั้ง desktop/tablet/mobile โดยไม่เสีย info
- **Khan Academy** = ตัดความรกออกหมด เน้น learning experience → minimal ดีกับ persona นักเรียน
- **Udemy** = search + personalized recommendation ช่วยให้หาเจอเร็ว
- **Skillshare** = student-first layout เน้น discoverability + categorization + preview

**Takeaway สำหรับเรา:** filter ยุบเป็นปุ่ม + การ์ด group สะอาด + เน้น discoverability (วิชา/ระดับชั้น)

## 2. Paywall (Freemium / Soft Paywall)
**อ้างอิง:** RevenueCat, Qonversion, webuild, Apphud

- **Soft paywall ชนะ** สำหรับสร้าง trust — ให้ลิ้มรส value ก่อนค่อยขวาง (ตรงกับ flow เราเป๊ะ: Guest/Free เข้าหน้าคลิปได้ก่อน)
- **ล็อกของมูลค่าสูง, ใช้ของฟรีเป็น teaser** ดึงคนเข้ามา
  → ใช้กับเรา: คลิปฟรีที่ตั้งไว้ = teaser, คลิปเต็ม group = ของล็อก
- **Timing สำคัญ** — อย่าขวางเร็วไป (ยังไม่เห็น value) หรือช้าไป (รำคาญ)
  → flow เรา: Guest โดน signup เร็ว / Free โดน payment ตอนกด Play = จังหวะ engagement สูง ✅
- **โปร่งใสเรื่องราคา + ยกเลิกง่าย** ลดความกลัวผูกมัด → เพิ่ม conversion
- **วิดีโอบน paywall เพิ่ม conversion ชัด** (เคสนึง +~80% revenue) → ใส่คลิปสั้นโชว์คุณค่าใน modal payment

**Takeaway:** flow ของเราถูกหลัก soft paywall อยู่แล้ว — เสริมด้วยความโปร่งใสราคา + teaser video ใน modal

## 3. Live + ตั้งเตือน/ปฏิทิน
**อ้างอิง:** LearnWorlds, AddEvent, Google Classroom

- **Reminder เพิ่ม attendance** — แจ้งเตือนก่อนเริ่ม (email/push) เป็นมาตรฐาน
- **Add to Calendar** ข้ามอุปกรณ์ (Google/Apple/Outlook) = พฤติกรรมที่ user คาดหวัง
- ปรับเวลาเตือนได้ (เช่น 1 วันก่อน / 1 ชม.ก่อน)

**Takeaway:** ปุ่ม "ตั้งเตือน" บนการ์ดไลฟ์ ควรผูกกับ add-to-calendar จริง + notification ก่อนเริ่ม

## 4. Responsive / Mobile-first
- นักเรียนไทยส่วนใหญ่ใช้มือถือ (สอดคล้อง notice เดิมที่โปรโมตแอป iOS)
- ออกแบบ touch-friendly ตั้งแต่ต้น, ปุ่ม/การ์ดขนาดนิ้วแตะได้
- Filter-as-button จะช่วยมากบนจอแคบ (sidebar ซ้ายพังบน mobile อยู่แล้ว)

## สรุป Insight ที่เอาไปใช้ออกแบบ (D)
1. Card group สะอาด ข้อมูลพอดี + ป้ายฟรี/ล็อกชัด
2. Filter ยุบเป็นปุ่ม → ดีทั้ง space และ mobile
3. Soft paywall + teaser + ราคาโปร่งใส (flow เดิมถูกแล้ว เสริม trust)
4. Live: ตั้งเตือน = add-to-calendar จริง + push ก่อนเริ่ม
5. Mobile-first / touch-friendly เป็น default ไม่ใช่ของแถม
