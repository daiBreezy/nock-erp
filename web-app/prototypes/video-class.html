quiz แบบฝึกหัด (Quiz) — กดทำได้เลย

description รายละเอียดบทเรียน

เรียนรู้การใช้ correlative conjunctions ทั้ง both…and และ not only…but also พร้อมโครงสร้างประโยคและตัวอย่างการใช้งานจริง โดยจะอธิบายหลักการจับคู่ประธาน-กริยาให้สอดคล้องกัน (subject-verb agreement) เมื่อใช้ both…and ที่ทำให้ประธานเป็นพหูพจน์เสมอ และการวางตำแหน่ง not only…but also ในประโยคทั้งแบบปกติและแบบ inversion พร้อมตัวอย่างข้อสอบจริงและจุดที่นักเรียนมักพลาด

  • กรณี inversion: ขึ้นต้นด้วย Not only + ช่วยกริยา + ประธาน
