## 1. Dashboard มีไว้ทำอะไร (หลักกรอง)

เปิดมาแล้ว **ภายใน 5 วิรู้ว่า "ต้องทำอะไรต่อ"** — ไม่ใช่หน้ารายงาน (นั่นคือ Reports). ทุกกล่องต้องตอบ 1 ใน 3:

| | คืออะไร |
|---|---|
| **① Action** — ต้องลงมือ | งานค้างที่ตัวฉัน กดแล้วไปทำต่อได้ (เช็คชื่อ, สรุป, อนุมัติ, ต่อคอร์ส) |
| **② Alert** — ต้องรู้ | ผิดปกติ/ด่วน ที่ควรเห็น (คาบไม่มีครู, คาบชน, ครูลา, บิลค้าง) |
| **③ Pulse** — รู้สถานะ | ชีพจรสาขาเป็น Visual (กราฟ) ไม่ใช่ตัวเลขซ้ำ |

**ของที่ไม่เข้า 3 ข้อนี้ → ไม่อยู่ Dashboard.** งานจิปาถะ (ครอบครัวไม่มีที่อยู่/LINE, ข้อมูลไม่ครบ) = **badge ในหน้าของมันเอง** · แชท = **badge ที่ sidebar** (ไหลตลอด ไม่มีจุดจบ ไม่ควรตะโกนบน Dashboard).

---

## 2. Dashboard ≠ Overview

- **Dashboard** = "งาน**ของฉัน**ที่ต้องลงมือ" (DO) — ทุกคนมี
- **Overview** = "สถานะ**ภาพรวม**ให้รับรู้" (KNOW) — เฉพาะคนคุมภาพรวม

ใช้ **ทาง ก**: หน้าเดียว 2 โซน — **DO ก่อน (บน) · KNOW ตาม (ล่าง)**.

---

## 3. โครงหน้า "มุมมองสาขา" (Admin + Manager เห็นเหมือนกัน)

> เจ้าของยืนยัน: Admin กับ Manager เห็นเหมือนกันเป๊ะ เพราะบางสาขามี Admin ไม่มี Manager / บางสาขากลับกัน

4 ชั้น บนลงล่าง:

| ชั้น | กล่อง | หมายเหตุ |
|---|---|---|
| 1 (บน) | **KPI Card หลัก** — เรียนอยู่ · รายรับ · ใหม่ · ลีด | ตัวเลข glance |
| 2 | **ต้องทำ (ฮีโร่ กว้าง)** │ **⚠️ ต้องรู้ไว้ (แคบ)** | ซ้าย=Action, ขวา=Alert |
| 3 | **คาบ (กว้าง)** │ **ลีด/ขาย (แคบ)** | |
| 4 (ล่าง) | **Pulse = กราฟ** — รายรับ · มาเรียน · เข้า-ออก · ลีดช่องทาง | Visual |

- **ฮีโร่ "ต้องทำ"** = ตัวเลข **ใหญ่** (visual หลักของ Dashboard = ขนาด) สีตามด่วน (แดง=ด่วนสุด เหลือง=ปกติ) + ring ความคืบหน้า + AI 1 บรรทัด ("เริ่มจาก…")
- **⚠️ ต้องรู้** = กรอบเหลือง แถวแน่นๆ + count
- Pulse เลือกกราฟตามธรรมชาติข้อมูล: รายรับ=เส้น/แท่งรายวัน · มาเรียน=โดนัท(มา/ลา/ขาด) · เข้า-ออก=แท่งเทียบ · ลีด=แท่งแนวนอน (reuse `Donut`/`DonutLegend`/`TopList` จาก reports)

### มุมมองครู (Teacher)
ตัดเหลือ **ชั้น 2 เฉพาะฮีโร่ "ต้องทำของฉัน"** (เช็คชื่อ/สรุป) + **คาบ** เท่านั้น — ไม่มี ⚠️สาขา, ลีด/ขาย, Pulse (เป็น noise สำหรับครู).

### Director / Area Manager
= มุมมองสาขา + Pulse ครอบหลายสาขา + ตัวสลับสาขา (`scope.select` เดิม).

## 4. Day / Week — คุมทั้งหน้า (default = วันนี้)

สวิตช์ `[ วันนี้ | สัปดาห์ ]` ที่หัวหน้า คุมทุกกล่อง · **ไม่มีเดือน** (เดือน+ = Reports). โหมดสัปดาห์มี `‹ 10–16 พ.ย. ›` เลื่อนสัปดาห์.

| กล่อง | วันนี้ (default) | สัปดาห์ |
|---|---|---|
| KPI หลัก | รายรับ/ใหม่ วันนี้ | ทั้งสัปดาห์ |
| ต้องทำ (ฮีโร่) | ค้างวันนี้ | ค้าง/ครบกำหนดในสัปดาห์ |
| ⚠️ ต้องรู้ | วันนี้ + ล่วงหน้า | ทั้งสัปดาห์ |
| คาบ | timeline รายชั่วโมงวันนี้ | **บอร์ด 7 วัน** (จ–อา, วันนี้ไฮไลต์, วันหยุดยังมีช่อง) |
| ลีด/ขาย | วันนี้ | ในสัปดาห์ |
| Pulse (กราฟ) | จังหวะวันนี้ | จังหวะทั้งสัปดาห์ |

## 5. การจัดกลุ่ม topic (จาก `domain/rules/today.ts`)

topics เดิมถูกแบ่งใหม่เป็น 3 ถัง (ตัดจิปาถะทิ้ง):

- **ฮีโร่ (Action):** `unmarked`, `summary_write`, `summary_approve`, `invoice_approve`, `unconfirmed`, `parent_requests`, `renewal`(+urgent), `exiting`
- **⚠️ ต้องรู้ (Alert):** `no_teacher`, `conflict`, `teacher_leave`, `unpaid`
- **ลีด/ขาย (Sales):** `lead_new`, `lead_follow_again`, `lead_quiet`, `survey_call`, `trial_idle`
- **ตัดออก → badge หน้าอื่น:** `often_leave`, `small_class`, `no_family`, `no_line`, `no_address`

> แก้การจัดกลุ่มที่ `components/dashboard/work-boxes.tsx` (`HERO_KEYS`/`ALERT_KEYS`/`SALES_KEYS`).
